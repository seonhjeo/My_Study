## /Init

CLAUDE.md(Codex:Agents.md)파일을 만들어주는 슬래시 커맨드

### CLAUDE.md

프로젝트의 컨텍스트, 코딩 컨벤션, 명령어 규칙 등을 정의해두는 설정 파일로, Claude 가 프로젝트를 이해하고 일관된 방식으로 코드를 작성하도록 안내하는 프로젝트 지침서 역할을 한다

CLAUDE.md는 매 대화 시작 시 자동으로 컨텍스트에 로드되기 때문에, 반복적으로 프로젝트 규칙이나 선호사항을 설명할 필요 없이 제한된 컨텍스트 윈도우를 효율적으로 활용할 수 있게 해준다.  
즉 토큰 낭비를 줄이면서도 항상 에이전트가 프로젝트 맥락을 파악한 상태에서 작업을 시작하도록 보장하는 핵심 컨텍스트 관리 도구이다.

## /Plan

Plan mode로 진입하는 커맨드

Plan mode는 에이전트가 바로 코드를 작성하지 않고 먼저 구현 계획을 세우고 사용자와 확인하는 단계를 거치게 함으로써, 잘못된 방향으로 대량의 토큰을 소비하는 것을 방지하고 정확한 결과물을 얻을 확률을 높여주는 비용/품질 최적화 전략이다.



## 토큰 관리

컨텍스트 윈도우가 가득 차면 에이전트의 성능이 저하되고 비용이 급증하기 때문에 아래의 두 명령어를 적절히 활용해 안정적인 작업 품질과 비용 효율을 유지해야 한다.

### /compact

현재 대화 내용을 요약해 컨텍스트 윈도우 사용량을 줄여준다.(Codex에서는 자동으로 실행되지만 수동으로 명령어를 입력해 추가 압축을 사용할 수 있다.)

### /clear

컨텍스트를 완전히 초기화하여 새 작업을 깨끗한 상태에서 시작할 수 있게 해준다.


## 세션 관리

| 작업                      | Claude Code         | Codex CLI             |
| ----------------------- | ------------------- | --------------------- |
| 방금 사용한 세션 이어서 실행        | `claude --continue` | `codex resume --last` |
| 세션 목록을 열어서 선택           | `claude --resume`   | `codex resume`        |
| **모든 디렉터리의 세션 목록**에서 선택 | -                   | `codex resume --all`  |
| 현재 세션 이름 변경             | `/rename 이름`        | `/rename 이름`          |



## Git

Git은 에이전트가 코드를 잘못 수정했을 때 즉시 이전 상태로 되돌릴 수 있는 안전망 역할을 하므로, AI와 협업할 때 자주 커밋하는 습관이 작업 손실을 방지하는 가장 중요한 보험이다.
